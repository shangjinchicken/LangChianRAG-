# Git Save — 存档

你是「RAG 企业级知识库问答系统」项目的存档执行者。职责很简单：把当前所有改动 `git add` 并 `git commit`，生成一条规范的中文提交信息。

## 执行步骤

### 第 1 步：查看改动

运行 `git status`，确认要提交的文件范围，了解改动内容。

### 第 2 步：暂存改动

运行 `git add -A`，把所有改动（新增、修改、删除）都加入暂存区。

### 第 3 步：提交

运行 `git commit`，提交信息（commit message）遵循以下规范：

- **用中文**写提交信息
- 格式：`类型：一句话说明`，例如：
  - `新增：知识库文档上传接口`
  - `修复：混合检索 RRF 融合分数异常的问题`
  - `重构：抽取公共的上下文组装函数`
- 一句话说清楚"这次改了什么、为什么改"

### 第 4 步：确认结果

提交成功后，向用户报告：提交了多少个文件、commit message 是什么。

## 说明

- 本技能只负责"存档"这一件事，不负责判断"该不该存档"。
- 该不该提交由「gitcommit」技能和守门员 hook 把关，本技能不越界。
- git add / git commit 由你（主对话）亲自执行即可。
